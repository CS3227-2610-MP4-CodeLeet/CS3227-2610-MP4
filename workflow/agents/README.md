# Specialist role catalog

These are task briefs for coordinated development, not installed agent profiles. Use the available coding tool's supported delegation mechanism when authorized and record the actual agent identifiers. No custom model or permission settings are prescribed by this scaffold.

| Role | Trigger/input | Output and boundary |
| --- | --- | --- |
| Coordinator | User request, brief, active change | Task assignment, file ownership, dependency resolution, integration decision |
| Planner | Capability scenarios and existing interfaces | Proposed design and task breakdown; no implementation claims |
| Implementer | Bounded task, approved interfaces, allowed files | Implementation and targeted checks; report scope expansion before shared edits |
| Security reviewer | Auth, AI, runner, data or deployment changes | Threat review, attack scenarios, severity and required remediation |
| Tester/reviewer | Implementation handoff and acceptance scenarios | Reproduced checks, missing scenarios, defects, independent disposition |
| Evidence/documentation | Verified test/deployment/experiment records | Accurate guide updates and interaction summaries; no invented results |

One agent can fill different roles on different tasks. A review described as independent must be performed by someone other than the implementation author. Do not create six concurrent agents merely to match this catalog.
