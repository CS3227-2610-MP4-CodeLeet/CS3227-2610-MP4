# Project status

CS3227 MP4 is a Coursemology-inspired programming assignment platform under development.

## Available in the repository

- A Next.js App Router foundation using TypeScript, React, Tailwind CSS, and pnpm.
- A development-only synthetic student assignment and code-entry preview.
- An opt-in local preview that runs Python and compiles/runs supported Java programs entirely in the browser.
- A fresh local Supabase configuration, profile and trusted-role migration, and database access tests.

## Still in development

Application sign-in, assignment persistence, code submissions, instructor tools, AI assistance, grades, discussion threads, XP, hosted environments, and production browser-runner integration are not implemented. Student preview data and local practice results are not stored or graded.

See the [repository](https://github.com/CS3227-2610-MP4-CodeLeet/CS3227-2610-MP4) for current source and the [developer guide](https://github.com/CS3227-2610-MP4-CodeLeet/CS3227-2610-MP4/blob/develop/docs/DeveloperGuide.md) for setup and limits.
